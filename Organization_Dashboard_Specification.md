# Organization Dashboard Specification

## Tabs

1.  Overview
2.  Spend & Budget
3.  Requests
4.  Tokens
5.  Reliability
6.  Capacity

Each tab contains: - Filters - KPI cards - Charts - Tables - Interactive
hover states - Responsive layout

The Organization Dashboard is the baseline implementation for all other
roles. Do not redesign components. Extend only functionality where
required.

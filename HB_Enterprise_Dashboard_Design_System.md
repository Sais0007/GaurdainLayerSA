# HB Enterprise Dashboard Design System

## Purpose

This document is the single source of truth for all dashboards built in
the HB Theme.

## Core Principles

-   Preserve one consistent visual language across all roles.
-   Reuse components rather than redesigning.
-   Card-first layout.
-   Enterprise SaaS styling.
-   Information hierarchy over decoration.
-   Consistent hover, spacing, typography and motion.

## Layout

-   12-column responsive grid
-   Consistent page header
-   Global filters at top
-   Section cards with 24px padding
-   Uniform vertical spacing

## Typography

-   Font: Roboto
-   Page Title
-   Section Title
-   Card Title
-   KPI Value
-   Supporting Text
-   Table Header
-   Table Body
-   Tooltip
-   Badge All identical across every dashboard.

## Components

-   KPI Cards
-   Analytics Cards
-   Charts
-   Tables
-   Progress Bars
-   Tooltips
-   Filters
-   Buttons
-   Badges

## Interaction Rules

-   Hover elevation only
-   No layout shift
-   Tooltip via portal
-   Smooth 200ms transitions
-   Consistent shadows and border emphasis

## Charts

-   Consistent colors
-   Interactive tooltips
-   Same legends
-   Same spacing
-   Same axis typography

## Never Change

-   Card hierarchy
-   Typography hierarchy
-   Hover behaviour
-   Shadows
-   Border radius
-   Component spacing

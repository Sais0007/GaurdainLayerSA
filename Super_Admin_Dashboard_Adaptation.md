# Super Admin Dashboard Adaptation

## Base Rule

Reuse the Organization Dashboard exactly.

Do NOT change: - Layout - Charts - KPI cards - Hover effects -
Animations - Typography - Colors - Spacing

## Functional Difference

Add an Organization selector beside global filters.

Flow: Select Organization → Reload dashboard → Refresh all tabs with
selected organization's data

Additional permissions: - Cross-organization visibility - Organization
switching - Administrative actions

No visual redesign is permitted.
